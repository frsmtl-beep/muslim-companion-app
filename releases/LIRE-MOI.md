# Mon Lecteur TV — fichiers à télécharger

- [Guide visuel en couleur, 9 pages](Guide_visuel_Chromecast_Xtream.pdf?raw=true)
- [APK Android TV / Google TV 0.1.0](mon-lecteur-tv-0.1.0-debug.apk?raw=true)
- [Empreinte SHA-256 de l’APK](SHA256SUMS.txt)

Le guide présente l’installation sur Chromecast compatible APK et l’import Xtream.
Le lecteur inclut Xtream pour les chaînes en direct, M3U, catégories et favoris.
Android 8 ou ultérieur est requis. Les identifiants Xtream se saisissent directement
dans l’application ; aucune source payante ni aucun compte n’est fourni.

L’APK est une version de test signée avec une clé debug. Compilation et signature
vérifiées ; 11 tests logiciels réussis. Les essais sur votre Chromecast physique,
la lecture prolongée, la télécommande et la persistance après relance restent à faire.
Pas de version iPhone, Cast, XMLTV ni films/séries dans cette version.

Pour télécharger depuis GitHub, ouvrir le fichier puis utiliser « Download raw file »
si le navigateur ne lance pas directement le téléchargement. Connectez-vous à votre
compte GitHub si le dépôt est privé.
